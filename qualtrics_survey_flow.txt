QUALTRICS SURVEY FLOW CONFIGURATION
=====================================

1. SURVEY FLOW SETUP
   - Create a new survey in Qualtrics
   - Go to Survey Flow
   - Add the following blocks in order:

2. EMBEDDED DATA VARIABLES

   Required Variables:

4. QUESTION BLOCKS
   Create the following question blocks:

   Block 1: Consent & Instructions
   - Text/Graphic question with consent information
   - Multiple Choice question: "I agree to participate" (Yes/No)

   Block 2: Trial 1
   - Text/Graphic question with the trial content
   - Matrix question for ratings (4 rows, 7-point scale)

   Block 3: Trial 2
   - Text/Graphic question with the trial content
   - Matrix question for ratings (4 rows, 7-point scale)

   Block 4: Trial 3
   - Text/Graphic question with the trial content
   - Matrix question for ratings (4 rows, 7-point scale)

   Block 5: Trial 4
   - Text/Graphic question with the trial content
   - Matrix question for ratings (4 rows, 7-point scale)

   Block 6: Trial 5
   - Text/Graphic question with the trial content
   - Matrix question for ratings (4 rows, 7-point scale)

   Block 7: Post-Trial Perceptions
   - Slider question: Trial A perceived wait time (0-10 seconds)
   - Slider question: Trial B perceived wait time (0-10 seconds)
   - Slider question: Trial C perceived wait time (0-10 seconds)
   - Slider question: Trial D perceived wait time (0-10 seconds)
   - Slider question: Trial E perceived wait time (0-10 seconds)

   Block 8: Wrap-up Questions
   - Slider question: Maximum acceptable wait time (0-10 seconds)
   - Multiple Choice question: Preference (Streaming/No preference/Non-streaming)

   Block 9: Thank You
   - Text/Graphic question with completion message

5. DISPLAY LOGIC
   For each trial block, add display logic:
   - Show Block 2 (Trial 1) if trial_1_prompt is not empty
   - Show Block 3 (Trial 2) if trial_2_prompt is not empty
   - etc.

6. RANDOMIZATION WITHIN BLOCKS
   - Use Randomizer elements to randomize the order of trial blocks
   - This ensures participants see trials in random order

7. PIPING TEXT
   - Use piping to display the correct prompt text based on embedded data
   - Example: ${e://Field/trial_1_prompt} will show the prompt for trial 1
