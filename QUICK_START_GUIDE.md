```

```
1. Click big green "?? SAVE CHANGES" button

3. Done! ?

```

```

        - metric_type: "llm_judge"
        - weight: "0.9"
        - enabled: "true"
Step 3: Click "? Add Row" button
Step 4: Click "?? SAVE CHANGES"
Result: New row added!
```

### ??? Delete a Row
```

## ?? Tips for Success

### ? DO:
- ? Click "SAVE CHANGES" after editing
- ? Run the save cell after clicking save
- ? Use "true" or "false" for boolean values
- ? Use numbers without quotes (1.5 not "1.5")
- ? Check the file path shown in interface

### ? DON'T:
- ? Close notebook without saving
- ? Edit multiple files simultaneously
- ? Forget to run the save cell
- ? Use special characters in metric names

## ?? "Help, it's not working!"

### Problem: Can't find the notebook
**Solution**: 
1. Go to Databricks Workspace
2. Look in "Shared" or "Users/your-name"
3. Import the .py file again

### Problem: Table doesn't appear
**Solution**:
1. Click "Clear" ? "Clear State"
2. Click "Run All" again
3. Wait 10 seconds

### Problem: Save button does nothing
**Solution**:
1. Press F12 (open console)
2. Look for JSON output
3. Copy and paste in widget below
4. Run save cell

### Problem: "File not found" error
**Solution**:
- The editor creates the file automatically
- Check the path shown in the interface
- Try running all cells again

### Problem: Changes didn't save
**Solution**:
1. Make sure you clicked "?? SAVE CHANGES"
2. Make sure you ran the cell below
3. Check for error messages
4. Try refreshing and running again
