STEP 3: PREPARE YOUR CSV FILES
???????????????????????????????????????????????????????????????????

You need 2-3 CSV files:

1. REQUIRED: metrics_config.csv
????????????????????????????????
Columns:
- name: Metric name (e.g., "Accuracy")
- type: binary, 1-5_scale, or percentage
- description: What this metric evaluates
- grading_rubric: How to score it
- threshold: Pass threshold (e.g., "1" or "4")
- ground_truth_file_path: Optional (e.g., "ground_truth.csv")
- ground_truth_column: Optional (e.g., "correct_answer")

Example:
name,type,description,grading_rubric,threshold,ground_truth_file_path,ground_truth_column
Accuracy,binary,Check factual accuracy,Score 1 if correct...,1,ground_truth.csv,correct_answer
Relevance,1-5_scale,Check relevance,5=Perfect...,4,,

2. REQUIRED: evaluation_data.csv
????????????????????????????????
Columns:
- sample_id: Unique identifier
- prompt: The user question
- response: The AI response to evaluate

Example:
sample_id,prompt,response
1,What is 2+2?,The answer is 4
2,Capital of France?,Paris is the capital

3. OPTIONAL: ground_truth.csv
????????????????????????????????
Reference answers (only needed if metrics use ground truth)

Columns: ANY columns you want! ALL will be accessible
Example:
sample_id,correct_answer,context,source
1,4,Basic math,Math textbook
2,Paris,Geography,Atlas

TIPS & BEST PRACTICES
???????????????????????????????????????????????????????????????????

1. Start Small
   - Test with 2-3 metrics first
   - Use 5-10 samples for testing
   - Scale up once working

2. Use Clear Rubrics
   - Be specific in grading rubrics
   - Provide examples in rubric
   - Define edge cases

3. Ground Truth
   - Only needed for factual metrics (Accuracy)
   - NOT needed for subjective metrics (Relevance, Tone)
   - Can include ANY columns - all accessible!

4. Thresholds
   - Binary: usually 1 (must pass)
   - 1-5 scale: usually 3 or 4 (good enough)
   - Test and adjust based on results

5. Backups
   - Every change creates automatic backup
   - Backups saved with timestamp
   - Can restore from backup if needed

6. Iterative Testing
   - Run evaluation
   - Review results
   - Adjust metrics/rubrics
   - Re-run evaluation
